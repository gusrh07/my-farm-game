# 첫 번째 농장

계절은 누적 날짜에서 계산하며 봄·여름·가을·겨울이 28일마다 순환합니다.
순무는 봄·가을, 감자는 봄, 옥수수는 여름, 호박은 가을에 파종할 수 있습니다. 씨앗 구매는 모든 계절에 가능하고 기존 작물은 시들지 않습니다.
옥수수는 물 준 날 4일, 씨앗 40G·판매 90G이며 호박은 6일, 씨앗 60G·판매 140G입니다. 순무는 테스트용 1일을 유지합니다.
시작 시 오늘·내일 날씨는 맑음입니다. 취침 시 예보를 오늘 날씨로 옮기고 새 내일 날씨를 비 확률 20%로 추첨합니다.
비 오는 아침에는 모든 밭이 젖으며 새로 간 땅도 즉시 젖습니다. 성장에는 오늘의 날씨만 적용하고 다음 날 비를 소급 적용하지 않습니다.
오늘·내일 날씨는 저장되며 로드 시 재추첨하지 않습니다. 날씨가 없는 기존 저장은 맑음으로 복원합니다.
이 방식은 로드만으로 오늘·내일 날씨가 바뀌는 것을 막지만, 로드 후 다시 잠들 때 새로 뽑는 예보까지 고정하지는 않습니다.

에너지는 100으로 시작하며 성공한 호미질에 2, 물 주기에 1을 사용합니다.
부족하면 해당 도구만 막히고 기절하지 않습니다. 이동·상점·심기·수확은 계속 가능합니다.
N 또는 자정 취침 시 100으로 회복합니다. HUD에 잔량이 표시되고 선택 도구의 에너지가 부족하면 앞 타일 테두리가 빨갛게 바뀝니다.
소모량은 `src/state.ts`의 `TOOL_COST`에서 조절합니다. 에너지도 저장되며 기존 저장은 100으로 불러옵니다.

Phaser 3 + TypeScript + Vite로 만든 타일맵·충돌 프로토타입입니다.
Node.js 20.17 이상에서 시작할 수 있습니다.

```sh
npm install
npm run dev
```

터미널에 표시된 주소를 브라우저로 여세요.
화살표 방향키로 이동하고 R로 시작 위치로 돌아갑니다.
화면 경계에서 멈추며 대각선 이동도 동일한 속도를 유지합니다.

## 코드 읽는 순서

1. `src/main.ts`의 `new Phaser.Game`: 게임 설정
2. `MainScene.create`: 캐릭터 생성과 키보드 설정
3. `MainScene.update`: 입력 → 이동 계산 → 위치 갱신
4. `src/world.ts`: 2차원 맵 데이터, 타일 좌표, 앞 타일, 사각형 충돌

800×600 화면에서 맵은 32×32 타일 25열 × 18행(800×576)을 사용하고,
아래 24픽셀은 좌표와 방향 표시 영역입니다. 좌표는 0부터 시작합니다.
잔디(0)·흙(3)은 이동 가능하고 물(1)·벽(2)은 막힙니다.
플레이어는 통로를 편하게 지나가도록 24×24 크기입니다.
앞 타일은 플레이어 중심 타일에서 바라보는 방향으로 한 칸 떨어진 타일입니다.
대각선 입력은 가로 방향을 우선하며 정지해도 방향을 유지합니다.
노란 테두리는 이동 가능한 앞 타일, 붉은 테두리는 막힌 앞 타일입니다.

`npm test`로 좌표 변환, 물·벽 충돌, 몸체 겹침, 빠른 이동, 벽을 따라 이동하는 동작을 확인합니다.

`npm run build`로 타입 검사와 로컬 빌드를 수행합니다. 외부 배포는 하지 않습니다.

## 이후 단계

호미질: 잔디 앞에서 Space를 누르면 앞 타일 한 칸을 갑니다. 길게 눌러도 한 번만 작동합니다.
흙·물·벽·맵 밖과 이미 갈린 땅은 무시합니다. R은 위치와 방향만 초기화합니다.
`src/farming.ts`의 `FarmField`가 경작 상태를 별도 Map에 저장하며 지형 데이터는 바꾸지 않습니다.
`toJSON()`은 직렬화용 스냅샷을 반환하고 `FarmField.load(entries)`는 밭을 복원합니다.

## 작물 키우기

숫자 1: 호미, 2: 물뿌리개, 3: 선택한 씨앗, 4: 수확을 선택합니다.
Space는 선택 도구 사용, N은 하루 넘기기입니다. 두 키 모두 누른 순간 한 번만 작동합니다.
06:00에 시작하고 현실 7초마다 게임 시간 10분이 흐릅니다. 24:00이 되면 자동 취침하여 다음 날 06:00으로 넘어갑니다. 하루는 현실 12분 36초입니다.
N으로 즉시 다음 날 06:00으로 이동할 수 있습니다. 비활성 탭에서는 게임이 일시 정지될 수 있습니다.
시간 속도는 `src/state.ts`의 `REAL_MS_PER_GAME_10MIN`(기본 7000ms)에서 조절합니다.
R은 위치와 방향만 초기화하고 날짜와 밭은 유지합니다.

제자리에서 `1 → Space → 3 → Space`로 갈고 심은 다음,
`2 → Space`로 물을 주고 자동으로 다음 날이 될 때까지 기다리거나 N을 누르세요.
이후 `4 → Space`로 수확합니다. 물 없이 N을 누르면 성장이 멈춥니다.

`src/crops.ts`에 순무(테스트용 1일)·감자(5일)의 성장 일수, 가격, 색상이 있습니다.
순무는 물을 준 뒤 다음 날짜 전환 때 다 자랍니다.
C로 순무/감자 씨앗을 선택하고 도구 3으로 심습니다. 감자는 물 준 날 5번이 필요합니다. 물은 무제한이며 씨앗은 심기 성공 시 한 개 소비합니다.
`FarmField.advanceDay()`가 모든 밭의 성장과 물 상태 초기화를 처리합니다.
성숙한 작물은 더 커지지 않고, 수확하면 작물만 사라져 다시 심을 수 있습니다.
수확물은 인벤토리에 들어갑니다. 같은 작물을 반복 수확할 수 없습니다.
`npm test`는 기존 충돌과 함께 성장·물 초기화·수확·재파종·직렬화를 검사합니다.

## 인벤토리와 상점

`src/state.ts`의 GameState에 날짜, 게임 시각, 100G, 순무 씨앗 5개, 밭 상태를 모았습니다.
E로 상점을 열고 ←→로 구매/판매, ↑↓로 항목을 선택하고 Space로 1개씩 거래합니다. E 또는 Esc로 닫습니다.
순무가 없으면 판매하지 않습니다. `sellAllCrops` 함수는 향후 전체 판매 UI를 위해 유지합니다.
이동은 화살표 방향키만 사용합니다. 거래 키는 누를 때 한 번만 작동합니다.
돈과 선택한 씨앗의 수량은 화면 위 상태창에 표시되고, 좌표·밭 상태는 기존 아래 표시줄에 남습니다.
`src/ShopScene.ts`는 별도 상점 씬이며, 열린 동안 main 씬과 하루 타이머를 멈춥니다. 기존 S/B 거래 단축키는 제거했습니다. `src/shop.ts`는 UI와 분리된 거래 로직입니다. 돈 부족이나 잘못된 수량이면 구매하지 않습니다.
순무 1개를 판매하면 140G가 되고, 순무 씨앗 1개를 구매하면 120G와 씨앗 5개가 됩니다.
`GameState.serialize()`는 버전이 포함된 JSON 문자열을 반환하며 `load()`는 검증 후 상태를 복원합니다.
상점을 닫고 F2로 localStorage에 저장, F4로 불러옵니다. 같은 브라우저와 주소(포트 포함)에서 사용할 수 있는 저장 슬롯 하나이며 F2는 기존 저장을 덮어씁니다. 자동 저장·자동 불러오기는 없습니다. 새로고침 후 F4로 이어 할 수 있습니다. 날짜·게임 시각·돈·인벤토리·선택 씨앗·경작/물/작물 상태를 저장합니다. 위치·방향·선택 도구는 저장하지 않습니다. 잘못된 저장 데이터나 저장 공간 접근 실패는 화면에 알리고, 불러오기 실패 시 현재 게임을 유지합니다.
아트, 사운드, NPC 등은 핵심 농사 루프가 완성된 뒤 추가합니다.

공식 참고: https://docs.phaser.io/phaser/getting-started/making-your-first-phaser-game

불러오면 저장된 시각을 복원하고 10분 미만의 누적 시간은 초기화합니다. 기존 시각 없는 저장 데이터는 06:00부터 재개합니다.

## Sunnyside 그래픽 적용

지형·울타리·물, 캐릭터 대기/걷기, 작물 성장 단계를 `src/art.ts`에서 렌더링합니다.
원본 16px 타일은 2배로 표시하며 기존 32px 격자와 충돌 규칙을 유지합니다.
`public/assets/sunnyside/`에 실행에 필요한 PNG와 캐릭터 프레임 메타데이터가 있습니다.
캐릭터 원본은 `scripts/export-character.mjs`로 PNG로 변환했습니다. 실행에 Aseprite는 필요 없습니다.
순무는 팩의 radish, 옥수수는 wheat 이미지를 임시로 사용합니다. 작물 이름·성장·가격은 기존 그대로입니다.
출처: https://danieldiggle.itch.io/sunnyside — Daniel Diggle.
원본 ZIP과 Aseprite 파일은 `assets-source/`에 보존합니다.

## 맵별 상태 구조 (저장 버전 2)

현재 플레이 가능한 맵은 `farm` 하나입니다. `GameState.maps[mapId]`가 밭·장식·건물·상자를 보관하고,
`currentMap`과 `map` 접근자가 현재 맵을 가리킵니다. 기존 `field/props/buildings/chests` 접근자는
현재 맵으로 연결됩니다. 지형·포털·맵 전환 기능은 이번 단계에 추가하지 않았습니다.

저장 키는 기존 `my-farm-game:save:v1`을 유지하지만 JSON의 `version`은 2입니다.
옛 version 1의 평면 데이터를 `maps.farm`으로 이관하며, 건물이 없는 옛 저장에는 초기 집을 사용합니다.
모든 맵의 검증이 끝나기 전에는 현재 게임 상태를 변경하지 않습니다.

실제 세이브 백업은 게임을 실행한 원래 주소의 개발자 도구 → Application → Local Storage에서
`my-farm-game:save:v1` 값을 별도 파일에 복사하세요. localhost·127.0.0.1·포트·itch.io는 저장 공간이
다를 수 있습니다. `tests/fixtures/legacy-save-v1.json`은 호환성 검증용 샘플이며 사용자 백업이 아닙니다.
새 형식으로 저장한 파일은 예전 게임 버전에서 읽을 수 없으므로, 되돌릴 때는 옛 세이브 백업도 사용하세요.
